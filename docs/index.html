Hide AI Replies

This free browser extension hides posts, replies, reposts and likes from AI reply bots on X, so the threads you read are written by people again.

Add to Chrome Install on Firefox

The Firefox Add-ons listing is still in review, so on Firefox you can install it by hand for now, as described below.

How it works

The extension downloads the public list of flagged accounts from blockedforaireply.levels.io, which @levelsio and @ryanvogel maintain, and refreshes it every six hours. While you browse x.com, it hides every post and reply written by an account on that list, every repost they make, and the rows they appear in on likes and repost lists. A notification is hidden only when every account in it is on the list, so a like from a real person is never swallowed by a bot that liked the same post.

When you open a flagged account's profile directly, their posts stay visible there, so you can still see what they wrote if you go looking for it.

Install it by hand

Chrome, Edge, Brave and Arc:

  1. Download hideaireplies.zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode in the top right corner.
  3. Click Load unpacked and choose the unzipped folder, then reload x.com.

Firefox: Firefox only keeps unsigned extensions until it restarts, so installing it for good will have to wait for the Firefox Add-ons review. To try it before then, open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and pick the manifest.json file inside the unzipped folder.

Privacy

The extension collects nothing and sends nothing anywhere. The only request it makes is to download the public list of usernames, and everything else happens inside your browser.

The list is a set of judgment calls by its maintainers, not proof that an account is a bot, and this extension is not affiliated with them or with X. If you think an account is listed by mistake, the list's site explains how to appeal. The source code is on git.borodutch.com and mirrored to GitHub, and the extension is made by Borodutch.
